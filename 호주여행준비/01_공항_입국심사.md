|---|---|---|---|---|---|

## V1. 입국 흐름도 (단계별로 나오는 질문)

```
 ✈ 착륙 · 기내에서 입국신고서(IPC) 작성
   │
   ▼
┌─────────────────────────────┐
│ ① 입국심사 Passport Control  │  SmartGate(자동) 또는 유인 카운터
│   질문: #1 목적 #2 기간       │
│        #3 숙소 #6 일행 #7 처음?│
└─────────────────────────────┘
   │
   ▼
┌─────────────────────────────┐
│ ② 수하물 찾기 Baggage Claim   │  ⚠ 짐 안 나오면 → Baggage Services
└─────────────────────────────┘    (C-상황 1)
   │
   ▼
┌─────────────────────────────┐
│ ③ 세관·검역 Customs/Biosecurity│  신고서 확인 → 레인 배정
│   질문: #4 신고 #5 음식        │
│        #8 짐 직접? #9 약       │
└─────────────────────────────┘
   │
   ├── 신고 없음 ─────────────► 바로 출구
   │
   └── 신고 있음 ──► ④ X-ray·검사  질문: #10 벨트에 올리기
                       │          ⚠ 반입 불가 시 폐기 (C-상황 2)
                       ▼
                  🚪 출구 Arrivals Hall → 기차·택시
```

## V2. 음식물 신고 판단 트리

```
 음식 가지고 있나?
   │
   ├─ 없음 ───────────────────────────► IPC "No"
   │
   └─ 있음 ─► 고기·유제품·계란·생과일·씨앗 포함?
                │
                ├─ 예 ─► 신고 + 검사 (반입 불가 가능성 높음)
                │
                └─ 아니오 (과자·라면·포장식품)
                        │
                        └─ 그래도 IPC "Yes" + 신고 ✅
                           (신고하면 대부분 통과, 미신고 적발 시 벌금)
```
> 라면 스프에 고기 성분이 들어 있을 수 있으니 무조건 신고하는 쪽이 안전합니다.

## V3. 연음 분해: 왜 안 들리는가

| 실제 발화 | 단어 분해 | 소리 변화 | 들리는 덩어리 |
|---|---|---|---|
| How long ya here for? | How · long · **are you** · here · for | are you → **ya** (축약) | 하울롱 · 야 · 히어퍼 |
| Anythin' to declare? | anything · to · declare | -ing → **-in'** (g 탈락) | 에니띤 · 터 · 디클레어 |
| Got any food on ya? | **Have you** got · any · food · on · **you** | 주어·조동사 생략, you → ya | 갓에니 · 푸돈야 |
| Pack 'em yourself? | **Did you** pack · **them** · yourself | 앞부분 통째로 생략, them → 'em | 팩컴 · 여셀프 |
| Pop it up on the belt for us. | pop · it · up · on · the · belt | t가 r/ㄹ처럼 약화 (flap t) | 파삐럽 · 온더 · 벨트 |
| Carryin' any meds? | **Are you** carrying · any · medication | 생략 + 단어 축약 (meds) | 캐린 · 에니 · 메즈 |

**듣기 포인트:** 문장 앞부분(Are you / Did you / Have you)은 거의 들리지 않으므로 **문장 끝의 핵심 단어**에 집중하세요.

## V4. 호주 모음 발음: 헷갈리는 단어

| 철자 | 미국식 | 호주식으로 들림 | 공항에서 혼동 예시 |
|---|---|---|---|
| day / stay | 데이 | **다이** / 스**타이** | "Where ya **stayin'**?" → 스타이인 |
| mate | 메잇 | **마잇** | "Cheers, **mate**" → 치어즈 마잇 |
| no / go | 노우 | **나우** | "**No** worries" → 나우 워리즈 |
| here / for | 히얼 / 포얼 | **히어** / **퍼** (r 없음) | "How long ya **here for**?" |
| today | 투데이 | 터**다이** | "Flyin' in **today**?" |
| meat ↔ meds | 밋 / 메즈 | 둘 다 짧게 들려 헷갈림 | 못 들으면 "Meat or meds?"로 되묻기 |

## V5. 즉답 구조 (IH 응용용)

```
 [핵심 답]  +  [보충 1개]  +  (선택) [되묻기/확인]
 ─────────    ───────────     ──────────────────
 "Holiday."   "Sydney, then    "Is that okay?"
              Melbourne."

 예) Q. How long ya here for?
     A. About twelve days. ── We fly out on the 11th.
```

## 🎙 롤플레이 프롬프트: 공항 (10/15, AI 음성 모드)

```
지금부터 너는 시드니 공항의 호주 입국심사관(ABF officer)이고, 이어서 세관·검역 직원(Biosecurity officer) 역할도 맡아.
나는 OPIc IH 수준이지만 오랜만에 영어를 써서 반응이 느린 상태고, 호주 악센트 알아듣기가 약해.

[상황 설정]
- 일정: 2026-10-31 시드니 도착, 11-11 멜버른 출국, 성인 2명 (나 + 동행 1명)
- 숙소: 시드니 CBD 호텔 → 멜버른 호텔
- 짐: 포장 과자, 컵라면(스프에 고기 성분 가능), 감기약·진통제
- 입국신고서에는 음식 "Yes" 체크함

[진행 순서]
1단계 입국심사: 방문 목적·기간·숙소·일행·방문 경험·직업 중 4~5개를 골라 물어봐
2단계 세관·검역: 신고 물품 확인 → 음식·약 세부 질문 → 가방 검사 요청
3단계 돌발 상황: 아래 중 1개를 무작위로 넣어줘
  - 컵라면 일부 폐기 요청
  - 수하물 미도착으로 Baggage Services 안내
  - 귀국 항공권 확인 요청

[말하기 규칙]
- 호주 원어민처럼 실제 속도로, 축약·생략(ya, 'em, anythin', Are you 생략 등)을 섞어서 말해
- 한 번에 한두 문장만 말하고 내 답을 기다려
- 내가 되물으면 처음엔 같은 속도로 다시 말하고, 두 번째에만 천천히 말해줘
- 내 답이 너무 짧거나 애매하면 실제 심사관처럼 추가 질문을 해

[종료 후 한국어로 표 정리]
1) 내가 못 알아들은 표현 | 실제 발화 | 들리는 발음
2) 내 답변 | 더 자연스러운 표현
3) 반응이 늦었던 질문 | 바로 쓸 수 있는 즉답 표현
4) 오늘 점수: 질문 이해율(이해한 질문 수/전체), 평균 반응 속도 평가(빠름·보통·느림)

"Next please!"로 시작해줘.
```
