## H. 출발 전 자가 점검 체크리스트

### 📝 출발 전 필수

- [ ] ETA(전자여행허가) 승인 확인 (동행자 포함)
- [ ] 입국신고서 방식(종이 IPC / 디지털) 최신 정보 확인
- [ ] 여행자보험 가입·증권 영문본 저장
- [ ] 숙소 주소 영어로 휴대폰 메모 저장
- [ ] Type I 어댑터 2개 이상
- [ ] 각 상황 '확인 필요' 항목 재확인 (요금·규정)

### ✈️ 공항

- [ ] 예상 질문 10개 중 8개 이상 자막 없이 이해 (듣기 카드 8/10)
- [ ] 체류 기간·숙소·목적을 3초 안에 답하기
- [ ] 음식물 신고 문장 막힘 없이 말하기

### 🏨 호텔

- [ ] 듣기 카드 8/10 이상
- [ ] 예약 누락 상황 대응 문장 말하기
- [ ] 방 문제 요청 공식(쿠션+문제+요청)으로 말하기

### ☕ 식당·카페

- [ ] 듣기 카드 8/10 이상
- [ ] 커피 주문 (메뉴+우유+매장/포장) 한 문장으로
- [ ] surcharge·카드 거절 대응

### 🚋 교통

- [ ] 듣기 카드 8/10 이상
- [ ] 길 설명 듣고 방향 복창하기
- [ ] 국내선 수하물 질문 대응

### 🛒 쇼핑

- [ ] 듣기 카드 8/10 이상
- [ ] Credit or savings? 즉답
- [ ] 환불 공식 4단계로 말하기
- [ ] TRS 조건 설명할 수 있음

### 💊 비상

- [ ] 듣기 카드 8/10 이상
- [ ] 증상 공식으로 말하기
- [ ] 000 통화 시 첫 두 문장 말하기 (서비스 종류 + 상황)

### 🎙 종합

- [ ] 종합 롤플레이 3회 완료
- [ ] 되묻기 표현 10개 중 5개 이상 실제로 사용
- [ ] 전체 섞어 듣기 모의고사 80% 이상
